# Stock Pulse (주식 포트폴리오 분석 앱 MVP)

한국 개인투자자를 위한 반응형 웹/PWA 형태의 주식 포트폴리오 분석 서비스입니다.

> **핵심 목적**  
> *"내가 보유한 주식에 중요한 변화가 생겼는지, 그 변화가 왜 중요한지, 현재 종목의 투자 매력도가 어떻게 변했는지를 카드 한 장으로 이해하게 하는 것"*

---

## 1. 제품 핵심 철학 & 특징

1. **평균매수가와 종목 평가의 엄격한 분리**
   - 종목 자체의 향후 12개월 관점 투자 매력도 점수(1.0~10.0) 계산에는 사용자의 평균매수가가 **절대 반영되지 않습니다**.
   - 평균매수가, 수익률, 비중, 설정 한도 초과 여부는 별도의 **'내 상황'** 섹션에서만 독립적으로 안내합니다.
2. **순수 결정론적 점수 계산 엔진 (Deterministic Score Engine)**
   - AI가 임의로 점수를 생성하지 않으며, 5대 요인의 팩트 데이터를 코드에서 가중합하여 산출합니다.
   - 동일한 입력 데이터와 동일한 모델 버전(`v1.0.0`)이면 항상 100% 동일한 점수를 보장합니다.
   - 데이터 부족 시 임의 중립값을 채우지 않고 **'평가 보류(PENDING_EVALUATION)'** 상태를 표시합니다.
3. **5대 요인 가중합 체계**
   - 실적·현금창출: **25%**
   - 밸류에이션: **25%**
   - 시장 기대 변화: **20%**
   - 산업·외부환경: **15%**
   - 재무 회복력: **15%**
4. **2차원 독립 신뢰도 체계**
   - **근거 충실도** (높음 / 보통 / 낮음) × **전망 불확실성** (낮음 / 보통 / 높음)을 분리 표시합니다.
   - 예: 공식 10-Q 공시는 확실하나 규제 결과가 미정인 경우 *"근거 충실도: 높음 / 전망 불확실성: 보통"* 조합 지원.
5. **AI의 역할과 한계**
   - AI는 사실 추출, 기업 영향 쉬운 한국어 설명, 반대 근거, 모니터링 체크리스트 생성을 담당하며 점수를 절대 임의 조작하지 않습니다.
6. **불변 과거 스냅샷 & 정정 시스템(Correction)**
   - 과거 판단 기록(`AnalysisSnapshot`)을 덮어쓰지 않고 시간순 보존합니다.
   - 회계 오류나 공시 정정 발생 시 기존 분석을 삭제하지 않고 `Correction` 기록을 통해 이전 분석 → 잘못된 부분 → 정정된 사실 → 현재 판단 영향을 추적합니다.
7. **다중 종목 묶음 알림**
   - 동일 사건(예: 미 상무부 수출 규제)이 여러 종목(NVDA, AVGO 등)에 영향을 줄 경우 1개의 묶음 알림으로 통합 제공합니다.

---

## 2. 기술 스택 & 구조

- **프론트엔드**: React 19, TypeScript, Vite 8, Tailwind CSS v4
- **아이콘**: Lucide React
- **상태 관리 & 영속성**: Custom Repository + React Hook State (LocalStorage 영속화, 데모 리셋 지원)
- **테스트**: Vitest (결정론적 점수 연산, 가중합 기여도, 매수가 비간섭 검증)
- **PWA**: Web App Manifest, Service Worker 오프라인 캐싱 지원

---

## 3. 실행 방법

```bash
# 의존성 패키지 설치
npm install

# 개발 서버 실행
npm run dev

# 단위 테스트 실행 (Vitest)
npm test

# 프로덕션 빌드
npm run build
```
